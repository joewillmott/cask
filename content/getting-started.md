# Getting Started

Getting cask running takes about five minutes. You need a web host that runs PHP, access to its file manager, and the cask zip file. That's it.

This section walks you through installation, setting up your site identity, writing your first content, and customising the design to match your brand.

- [[installing-cask]] — upload cask to your host and get to first page load
- [[content-management]] — write and structure your markdown files
- [[brand-styling]] — customise colours, fonts, and layout using the admin panel
- [[navbar]] — set your site title, logo, and navigation links
